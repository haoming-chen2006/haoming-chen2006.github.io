    Gateway

    The gateway (paperd) runs on your Mac and lets this page draft, edit and chat with the note agent. Without it the notebook is read-only.

    Easiest: run python3 gateway/paperd.py pair — it opens this page with a pairing link.

    Reprocess note

    Anything you add here is appended to the raw notes (never overwritten), then the agent rewrites the note.
